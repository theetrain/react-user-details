# React User Details

This application demonstrates some basic functional requirements:

- Fetch and display some users within a card grid
- Show user details in a modal
- Provide user feedback mechanisms

As well as some non-functional requirements:

- Unit tests
- End to End tests
- Project structure

## Development

```bash
# one-time step
npm install

# run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses
[`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts)
to automatically optimize and load [Geist](https://vercel.com/font), a new font
family for Vercel.

## Test production build

```bash
# one-time step
npm install

# build for production
npm run build

# run production build
npm start
```

## Run tests

```bash
# unit tests
npm run test:unit

# end to end tests
npm run test:e2e
```
